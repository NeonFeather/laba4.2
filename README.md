# Pascal-- IDE - Структура проекта

## Используемые библиотеки

### Qt Framework (версия 6.x)
- **QtCore** - базовые классы, сигналы/слоты, строки, контейнеры
- **QtWidgets** - GUI компоненты (окна, кнопки, меню, редактор)
- **QtGui** - графика, шрифты, цвета

## Структура проекта
- **core/** - Интепретатор
- **interface/** - Интерфейс приложения
- **interface/theme** - Тема приложения


## Проделанная работа

### 1. Интерфейс
- **Текстовый редактор** 
- **Консоль вывода**
- **Меню и тулбар** 
- **Поддержка файлов**

### 2. Лексический анализатор (Lexer)
- Разбивает исходный код на токены
- Поддерживает ключевые слова Pascal (`program`, `var`, `begin`, `if`, etc.)
- Распознаёт операторы (`:=`, `+`, `-`, `*`, `/`, `mod`, `div`, `=`, `<`, `>`, etc.)
- Обрабатывает комментарии `{...}` и `(*...*)`

### 3. Синтаксический анализатор (Parser)
- Строит **иерархический список (AST)** программы
- Проверяет синтаксическую корректность
- Поддерживает:
  - Объявления констант и переменных
  - Присваивания
  - Условный оператор `if-then-else`
  - Составной оператор `begin-end`
  - Ввод/вывод `Read/Write`

### 4. Таблица символов (Symbol Table)
- Реализована на основе **хеш-таблицы** (`QHash`)
- Хранит информацию о константах и переменных
- Разделяет символы по типам (`integer`, `double`, `boolean`, `string`)

### 5. Вычисление выражений (Postfix Evaluator)
- Преобразует выражения в **постфиксную форму**
- Поддерживает арифметические операции (`+`, `-`, `*`, `/`, `div`, `mod`)
- Операции сравнения (`=`, `<>`, `<`, `<=`, `>`, `>=`)
- Логические операции (`and`, `or`, `not`)

### 6. Выполнение программы
- Интерпретация AST с обходом дерева
- Пошаговое выполнение операторов
- Обработка ввода через диалоговые окна
- Вывод результатов в консоль


## Особенности реализации

| Компонент | Структура данных |
|-----------|------------------|
| AST | Иерархический список (`std::vector<std::unique_ptr<ASTNode>>`) |
| Таблица символов | Хеш-таблица (`QHash<QString, SymbolInfo>`) |
| Выражения | Постфиксная форма (стековое вычисление) |
| Токены | Линейный список (`std::vector<Token>`) |

## Пример поддерживаемой программы

```pascal
program Example;
const
    Pi: double = 3.1415926;
var
    num1, num2: integer;
    Res, d: double;
begin
    num1 := 5;
    Write("Enter even integer: ");
    Read(num2);
    Write("Enter real number: ");
    Read(d);
    if (num2 mod 2 = 0) then
    begin
        Res := (num1 - num2 * 5 div 2) / (d * 2);
        Write("Result = ", Res);
    end
    else
        Write("Invalid input");
end.
```
